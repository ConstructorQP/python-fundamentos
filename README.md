# Fundamentos de Python

Primeros ejercicios de Python del ciclo de ASIR: programas de consola que trabajan entradas y salidas, operadores, condicionales y bucles.

## Contenido

| Ejercicios | Tema |
|---|---|
| `001` – `003` | Salidas con `print`, comentarios y entrada de datos con `input` |
| `004` – `007` | Operadores aritméticos y de comparación, calculadora sencilla y calculadora de IVA |
| `008`, `011` – `014` | Estructuras condicionales (`if`, `else`, `elif`) y rangos de edad |
| `009` – `010` | Bucle `for` y ejemplo de semanario |
| `plantilla calculos.py` | Plantilla base para programas de cálculo |

## Cómo ejecutarlos

```bash
git clone https://github.com/ConstructorQP/python-fundamentos
cd python-fundamentos
python 006-Caculadoradeiva.py
```

Solo necesitas Python 3; no hay dependencias externas.
